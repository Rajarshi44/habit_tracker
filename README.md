# GRIND: Execution Without Fluff.

> *Amateurs sit and wait for inspiration, the rest of us just get up and go to work.*

**GRIND** is a brutalist, no-nonsense productivity and habit tracking platform engineered specifically for developers, engineers, and deep-workers. It strips away the gamification, cute emojis, and visual clutter of traditional habit trackers to focus on one thing: **Absolute Consistency.**

---

## 🦅 The Philosophy
Most habit trackers want to be your friend. GRIND wants to be your coach. 
The interface is intentionally dark, editorial, and unapologetically minimal. There are no streaks to "protect" with gems, no social sharing, and no bright celebratory confetti. It is designed to look and feel like a high-end command center for your life.

## ⚡ Core Features

### 1. The Execution Dashboard
A distraction-free daily view. Mark your scheduled blocks as done, skipped, or failed. The dashboard automatically syncs with your current learning stages and dynamic college subjects to ensure you always know what you should be working on.

### 2. Dynamic Learning Pipeline
Stop wondering what tutorial to do next. Set up a sequence of learning stages (e.g., `HTML` → `JavaScript` → `React`).
Track your progress percentages. Once a stage hits `100%`, the dashboard seamlessly transitions your learning block to the next subject automatically. 

### 3. Automated Subject Rotation
Automate your study schedule. Enter a list of subjects (e.g., `DBMS, Computer Networks, Operating Systems`), and GRIND will rotate them into your daily study blocks automatically, ensuring no topic is left behind.

### 4. AI-Powered Stoic Intelligence
Powered by Gemini 3.1 Flash. Wake up to a personalized, data-driven daily briefing based on your actual performance data from the previous week and your current streaks. Receive brutal, honest weekly performance reviews that grade your execution (S/A/B/C/D).

### 5. Advanced Analytics Heatmaps
Track your active streaks and view detailed heatmaps of your execution over the last 90 days. Analyze your historical data to find the exact days your discipline drops, and fix the leak.

### 6. Cloud Synchronization
Backed by MongoDB. Log in securely from any device. Your entire protocol—tasks, history, pipeline, and settings—is seamlessly synchronized to the cloud in real-time.

## 🛠️ Setup & Initialization

To run GRIND locally:

```bash
# 1. Clone the repository
git clone https://github.com/Rajarshi44/habit_tracker.git

# 2. Install dependencies
cd habit_tracker
npm install

# 3. Start the development server
npm run dev
```

### Initializing the Protocol
When you load the app for the first time, click **"Initialize Default Protocol"** in the settings. This will instantly populate the database with a highly optimized daily schedule, including the rotating college blocks and the web-development learning pipeline.
